## Core Monitoring Story (to emphasize on website)
MySentry is fundamentally a **continuous safety monitoring** platform. The app:
1. Continuously monitors health vitals (SpO2, HR, BP, Temp) in real time
2. Tracks live location with configurable intervals
3. Connects the user to an Emergency Contact group AND a "Responding To" group
4. Provides one-tap PANIC button on phone AND watch
5. Enables Meet Safe check-ins for in-person meetings
6. Connects to 24/7 professional monitoring agents
7. Automated Call feature for hands-free emergency escalation

## User Onboarding Flow (to add to website)
Based on app screens, the setup flow is:
1. Download MySentry app (iOS / Android)
2. Create account / sign up
3. Choose plan (Free / Individual $15/mo / Family $30/mo)
4. Set up Emergency Contacts (add up to 3 members)
5. Set up "Responding To" contacts (people who monitor you)
6. Enable Location Sharing and set update interval
7. Pair smartwatch (optional but recommended)
8. Test PANIC button
9. Start monitoring — the app runs in background
