# Design Baseline Notes

## Whoop.com Key Patterns
- Full-viewport hero with background video/image
- Clean nav: Logo left, menu items center, CTA button right
- Menu items in uppercase, spaced out
- Hero text: Large serif-like font, left-aligned, overlaid on dark imagery
- Single CTA button below hero text ("JOIN NOW")
- Below hero: feature carousel with sliding cards
- Trust section: Celebrity/athlete endorsements with photos
- Accordion-style feature details section
- Clean, minimal layout with generous whitespace

## Oura Ring Key Patterns (from knowledge)
- Font/text sizing consistency baseline
- Blog layout baseline
- Clean typography with good hierarchy

## MySentry Constraints
- Light greenish palette (no black, no dark green)
- Max hero font: 55px
- Menu items: 28px
- CTA text: "Start 7-Day Free Trial" (or "Book a Demo" for B2B)
- High-contrast: black text on white/light backgrounds
- No em-dashes in content
